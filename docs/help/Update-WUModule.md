# Update-WUModule

## SYNOPSIS

Update PSWindowsUpdateNext module.

## SYNTAX

### Online (Default)

```
Update-WUModule -Online [-ComputerName <string[]>] [-Credential <pscredential>] [-Debuger] [-WhatIf]
 [-Confirm] [<CommonParameters>]
```

### Local

```
Update-WUModule -ComputerName <string[]> -Local [-Credential <pscredential>] [-Debuger] [-WhatIf]
 [-Confirm] [<CommonParameters>]
```

## ALIASES

## DESCRIPTION

Use Use Update-WUModule cmdlet to remote update PSWindowsUpdateNext module.
