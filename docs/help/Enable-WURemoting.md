# Enable-WURemoting

## SYNOPSIS

Enable firewall rules for PSWindowsUpdateNext remoting.

## SYNTAX

### __AllParameterSets

```
Enable-WURemoting [-LocalAccountTokenFilterPolicy] [-WinRMPublic] [-Debuger] [-WhatIf] [-Confirm]
 [<CommonParameters>]
```

## ALIASES

## DESCRIPTION

Use Enable-WURemoting cmdlet to enable nessesery firewall rules for PSWindowsUpdateNext remoting.
