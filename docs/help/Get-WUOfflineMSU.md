# Get-WUOfflineMSU

## SYNOPSIS

Get offline MSU package.

## SYNTAX

### __AllParameterSets

```
Get-WUOfflineMSU -KBArticleID <string> -Destination <string> [-AcceptAll] [-SkipSignatureCheck]
 [-UpdateID <string[]>] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## ALIASES

## DESCRIPTION

Use Get-WUOfflineMSU cmdlet to download MSU package from Microsoft Update Catalog website.
