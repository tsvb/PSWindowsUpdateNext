# Reset-WUComponents

## SYNOPSIS

Reset Windows Update components.

## SYNTAX

### __AllParameterSets

```
Reset-WUComponents [-WhatIf] [-Confirm] [<CommonParameters>]
```

## ALIASES

## DESCRIPTION

Use Reset-WUComponents cmdlet to reset all Windows Update components to default.
