# Remove-WUServiceManager

## SYNOPSIS

Remove windows update service manager.

## SYNTAX

### __AllParameterSets

```
Remove-WUServiceManager -ServiceID <string> [-ComputerName <string[]>] [-ScheduleJob <datetime>]
 [-Debuger] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## ALIASES

## DESCRIPTION

Use Remove-WUServiceManager cmdlet to unregister Windows Update Service Manager.
